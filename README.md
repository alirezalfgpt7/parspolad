# پورتال شرکتی و سامانه مدیریت یکپارچه پارس پولاد آقایی

## Pars Poolad Aghaee Knowledge-Based Co. — Wellhead & Downhole Engineering Portal

وب‌سایت رسمی، کاتالوگ فنی تجهیزات سرچاهی و درون‌چاهی، مدیریت پروژه‌ها/قراردادها/گواهینامه‌ها و پنل مدیریت تم‌محور شرکت دانش‌بنیان **پارس پولاد آقایی**.

---

## ویژگی‌های کلیدی معماری

- **کاملاً بدون CDN و بدون هوش مصنوعی/چت‌بات:** تمامی فونت‌ها (`@fontsource/vazirmatn`)، آیکون‌ها (`lucide-react`)، نقشه‌ها (`leaflet`)، اسلایدر (`swiper`) و انیمیشن‌ها (`motion`, `aos`) به‌صورت محلی نصب و باندل می‌شوند.
- **موتور تم داینامیک (CSS Variables):** تم پیش‌فرض «قرمز صنعتی (#B91C1C)»، تم‌های آماده قابل انتخاب، تم مستقل صفحه نخست، پیش‌نمایش زنده و تغییر حالت Dark/Light.
- **اسلایدر پیشرفته Hero:** مدیریت ترتیب Drag & Drop، افکت‌های Ken Burns / Parallax / Zoom / Fade / Slide، انیمیشن متن، ذرات و پشتیبانی از ویدیو MP4 و تصویر مجزا برای دسکتاپ و موبایل.
- **SearchableSelect سراسری:** تمامی منوهای کشویی در بخش عمومی و پنل ادمین مجهز به فیلد جستجو در ردیف اول هستند.
- **ضداسپم فرم‌های عمومی:** CAPTCHA تصویری و محاسباتی self-hosted، honeypot و rate limit برای تماس، RFQ، ثبت‌نام و دیدگاه‌ها؛ بدون سرویس خارجی یا ذخیره پاسخ CAPTCHA.
- **دیدگاه مقاله با تأیید مدیر:** دیدگاه بازدیدکنندگان تا زمان moderation منتشر نمی‌شود و متن در فرانت‌اند به‌صورت امن و بدون اجرای HTML نمایش داده می‌شود.
- **آمار بازدید خصوصی:** شمارش تجمیعی روزانه با نمایش روزانه، ماهانه و بازه دلخواه در داشبورد؛ IP، شناسه و user-agent ذخیره نمی‌شوند.
- **تاریخ شمسی محلی:** انتخابگر Jalali باندل‌شده برای تاریخ انتشار مقاله، صدور گواهینامه و فیلتر بازه گزارش‌ها.
- **حذف امن محتوا:** حذف‌های مدیریتی با تأیید و بازخورد انجام می‌شوند و رکوردهای محتوایی با SoftDeletes از نمایش عمومی کنار می‌روند.
- **CMS و CRUD داینامیک:** صفحات و معرفی بخش‌های عمومی، FAQ دوزبانه، خدمات، محصولات، اخبار، شرکا، بنرها و دیگر محتوای سایت از دیتابیس مدیریت می‌شوند؛ منوی هدر/فوتر، نام و اطلاعات شرکت، CTA هدر، تاریخ بروزرسانی و استانداردهای فوتر از پنل تنظیمات قابل ویرایش‌اند و HTML پیش از نمایش پاک‌سازی می‌شود.
- **چرخه کامل کاربران و نقش‌ها:** اطلاعات کاربران قابل ویرایش و حذف نرم است؛ نقش‌های سفارشی و مجوزهایشان مدیریت می‌شوند، اما حذف نقش دارای کاربر و حذف/غیرفعال‌سازی حساب‌های حیاتی محافظت شده است.
- **مدیریت پیام‌ها:** وضعیت پیام و درخواست RFQ قابل‌پیگیری است و حذف مدیریتی پیام‌ها پس از تأیید به‌صورت نرم انجام می‌شود.
- **ساختار منابع:** تمامی فایل‌های اولیه شرکت در پوشه `منابع سایت/` سازمان‌دهی شده‌اند.

## اجرای پروژه

```bash
composer install
npm install
composer run dev
```

- آدرس سایت: `http://localhost:3000`
- آدرس API لاراول: `http://localhost:8000`
- آدرس پنل مدیریت: `http://localhost:3000/admin`
- مستندات OpenAPI: `docs/openapi.yaml`

فرانت‌اند با Vite اجرا می‌شود و درخواست‌های `/api` و `/storage` را به Laravel پروکسی می‌کند؛ منطق API و داده‌ها در ساختار استاندارد Laravel نگهداری می‌شوند.

---

## راه‌اندازی بک‌اند Laravel 13+ (PHP 8.5+)

ساختار Laravel مستقیماً در ریشه پروژه قرار دارد؛ بنابراین دستورهای Artisan را از همین پوشه اجرا کنید:

```bash
php artisan migrate
composer test
```

در نصب تازه، `.env.example` را به `.env` کپی کنید، دیتابیس را پیکربندی کنید و سپس `php artisan key:generate` و `php artisan migrate --seed` را اجرا کنید. برای دیتابیسی که قبلاً مهاجرت شده، ابتدا `php artisan migrate` و سپس `php artisan db:seed` را اجرا کنید تا جدول‌های cache، session و queue نیز ساخته شوند. فایل `.env` موجود را بازنویسی نکنید. این پروژه به‌صورت پیش‌فرض از MySQL استفاده می‌کند.

مهاجرت‌های جدید، جدول دیدگاه‌ها و آمار تجمیعی بازدید، metadata صفحات، ترجمه انگلیسی FAQ و ستون‌های حذف نرم (از جمله پیام‌های تماس و کاربران) را ایجاد می‌کنند؛ پس از دریافت تغییرات، `php artisan migrate` و سپس `php artisan db:seed` را پیش از استفاده اجرا کنید.

## اطلاعات ورود پیش‌فرض مدیر ارشد (Super Admin Bootstrap)

هنگام اجرای اولیه (دیتابیس خالی)، کاربر مدیر ارشد به‌صورت خودکار ایجاد می‌شود (قابل تغییر از `.env`):

- **ایمیل:** `admin@parspooladaghaei.ir`
- **رمز عبور:** `ParsPolad@1404`
- **مسیر ورود:** `/login` (و پنل ادمین در `/admin`)

> پس از اولین ورود، رمز عبور را از بخش پروفایل یا مدیریت کاربران تغییر دهید و در صورت نیاز احراز هویت دوعاملی (2FA) را فعال کنید.
